# 部署与配置指南

## 一、前置准备

| 项目 | 说明 | 是否必需 |
| --- | --- | --- |
| 小程序 AppID | 在 [微信公众平台](https://mp.weixin.qq.com) 注册「小程序」账号 | 必需 |
| 微信开发者工具 | [下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，Stable 版即可 | 必需 |
| 云开发环境 | 开发者工具内一键开通，有免费额度 | 必需 |
| 微信支付商户号 | 需企业主体小程序，个人主体无法使用支付 | 支付功能必需 |

> **个人主体小程序**：除「微信支付」外其余功能均可正常跑通。支付相关页面会提示
> `未配置微信支付商户号`，不影响下单、预约、会员和后台管理的调试。

---

## 二、导入项目

1. 打开微信开发者工具 → **导入项目**
2. 目录选择本仓库根目录，AppID 填你自己的（测试可选「测试号」）
3. 后端服务选择「微信云开发」

导入后把 `project.config.json` 里的 `appid` 改成你的真实 AppID：

```json
{ "appid": "wx这里换成你的appid" }
```

---

## 三、开通云开发

1. 工具栏点击 **云开发** → 开通 → 新建环境（如 `flower-prod`）
2. 记下环境 ID。代码里用的是 `DYNAMIC_CURRENT_ENV`，会自动指向当前环境，**无需手填**

---

## 四、部署云函数

云函数共 9 个。**首次部署请逐个操作**：

> 右键 `cloudfunctions/<函数名>` → **上传并部署：云端安装依赖**

部署顺序不限，建议按下表逐一确认：

| 云函数 | 作用 | 特殊配置 |
| --- | --- | --- |
| `login` | 授权登录、昵称头像、手机号 | 手机号功能需在 mp 后台开通「手机号快速验证」 |
| `shop` | 商品、分类、店铺信息 | — |
| `order` | 下单、查单、取消、收货 | — |
| `pay` | 微信支付统一下单 | 需配置商户号，见第六节 |
| `payCallback` | 支付结果回调 | 由 `pay` 指定调用，无需单独配置 |
| `reservation` | 预约订花 | — |
| `member` | 会员、优惠券、地址 | — |
| `admin` | 后台管理 | — |
| `seed` | 初始化数据与管理员 | 上线后建议删除 |

### 共享库说明

9 个云函数共用 `shared/common.js`。因为云函数各自独立打包、无法跨目录 `require`，
所以每个函数目录下都有一份复制（`cloudfunctions/<函数名>/common.js`）。

> **源文件为什么不放在 `cloudfunctions/` 下**：开发者工具会把 `cloudfunctionRoot`
> （即 `cloudfunctions/`）下的**每个子目录**都识别为一个云函数。共享库目录没有
> `index.js`，上传时必然报错。因此源文件放在仓库根的 `shared/`。
>
> 同理，**不要在 `cloudfunctions/` 下新建任何非云函数目录**。

**修改共享逻辑时，只改 `shared/common.js`，然后运行：**

```bash
bash scripts/sync-shared.sh
```

同步后需要重新上传受影响的云函数。

## 五、初始化数据库（一键完成）

数据库**不需要手动建集合**，小程序内置了一键初始化。

### 5.1 操作步骤

> 前提：`seed` 云函数已「上传并部署」。它是唯一没部署会导致初始化失败的函数。

1. 在开发者工具中**点击编译**运行小程序
2. 底部切到 **「我的」** 页
3. 首次运行会看到黄色提示条「⚠️ 还差最后一步」，下方有 **「🔧 一键初始化」** 按钮
4. 点击按钮 → 弹窗确认「一键初始化」→ 等待完成（约 5~10 秒）
5. 弹窗会列出执行结果，点击「开始使用」即可

这一步会自动完成三件事：

| 步骤 | 内容 |
| --- | --- |
| ① 创建集合 | 创建全部 10 个集合，已存在的自动跳过 |
| ② 授予权限 | 把**当前账号**设为店主（`role: admin`） |
| ③ 灌入数据 | 6 个分类、8 个示例商品、3 张优惠券、店铺信息与节日表 |

初始化是**幂等**的，可以反复点击：已存在的集合和数据不会重复创建。

### 5.2 初始化完成后

- 「我的」页出现 **「商家管理台」** 入口
- 首页能看到 8 个示例商品（图片位置显示 🌸 占位符）
- 可以正常下单、预约、领券了

> **商品图片需要自己上传**：示例数据不含图片。到
> 「商家管理台 → 商品与库存 → 编辑商品 → 商品图片」上传，图片会存入云存储。

### 5.3 如果初始化失败

**情况一：按钮点了没反应，或提示「seed 云函数未部署」**

右键 `cloudfunctions/seed` → **上传并部署：云端安装依赖**，然后重试。

**情况二：提示「当前环境不支持自动建集合」**

少数环境不允许云函数建集合，需要手动创建。到 **云开发控制台 → 数据库 → 集合管理
→ 新建集合**，逐个创建这 10 个（名称必须完全一致，区分大小写）：

```
users          categories     products       orders
reservations   coupons        user_coupons   addresses
settings       stock_logs
```

建完后回到小程序，**再点一次「🔧 一键初始化」**，剩下的授权与灌数据会自动完成。

**情况三：「我的」页连按钮都没有**

说明 `seed` 云函数没部署成功。到 **云开发控制台 → 云函数** 确认列表里有 `seed`；
没有就重新上传。也可以右键 `login` 云函数 → 「本地调试」手动执行一次
`{"action": "login"}`，看报错信息。

**情况四：提示集合不存在 / 数据读取失败**

按下表确认集合是否齐全，缺失的用情况二的方法补齐。

### 5.4 集合清单与权限

**重要**：云函数创建的集合一律是默认权限「仅创建者可读写」，无法在创建时指定其他权限。
这对本项目没有影响——所有读写都走云函数，不依赖小程序端直连，设置见本节末尾的说明。

各集合用途如下：

| 集合名 | 用途 |
| --- | --- |
| `users` | 用户档案、会员等级、角色 |
| `categories` | 商品分类 |
| `products` | 商品 |
| `orders` | 订单 |
| `reservations` | 预约单 |
| `coupons` | 优惠券模板 |
| `user_coupons` | 用户已领券 |
| `addresses` | 收货地址 |
| `settings` | 店铺、轮播、支付配置 |
| `stock_logs` | 库存变更日志 |

> 本项目所有数据读写都走云函数（以管理员身份运行），**不依赖小程序端的数据库直连权限**。
> 因此即使集合权限保持默认的「仅创建者可读写」，功能也完全正常，且更安全。

### 5.5 追加管理员

第一个店主通过一键初始化产生。之后再添加管理员（比如店员的账号）需要用
`seed.grantAdmin`，参数是对方的 `openid`（对方需先在小程序里登录过一次）：

```js
// 云开发控制台 → 云函数 → seed → 云端测试，传入：
{ "action": "grantAdmin", "phone": "13800138000" }
```

### 5.6 建议的数据库索引

数据量上来（订单过千）后，在控制台为这些字段建索引，否则查询会变慢：
**数据库 → 选集合 → 索引管理 → 新建索引**

| 集合 | 索引字段（全部升序，除注明外） |
| --- | --- |
| `products` | `status`、`categoryId`、`sales`（降序） |
| `orders` | `_openid`、`status`、`createdAt`（降序）、`orderNo`（唯一） |
| `reservations` | `_openid`、`deliveryDate`、`status` |
| `user_coupons` | 联合索引：`_openid` + `status` |
| `addresses` | `_openid` |

> 索引不是必须的，初始调试阶段可以跳过；`orders.orderNo` 建议建成**唯一索引**，
> 可以从数据库层面杜绝订单号重复。

## 六、配置微信支付

### 6.1 开通云调用支付

1. 云开发控制台 → **扩展能力 / 微信支付** → 绑定商户号
2. 在商户平台完成「**云开发支付授权**」确认

### 6.2 写入商户号

在 `settings` 集合中创建一个 **文档 ID 为 `pay`** 的记录：

```json
{
  "_id": "pay",
  "subMchId": "1900000109",
  "shopName": "花知道鲜花"
}
```

也可以改用环境变量 `WX_SUB_MCH_ID`（在云函数配置中设置）。

### 6.3 支付链路说明

```
小程序 order.create          → 事务扣库存、写订单（pending_pay）
     → pay.prepay            → cloudPay.unifiedOrder，返回支付参数
     → wx.requestPayment     → 用户输入密码
     → 微信支付后台           → 回调 payCallback 云函数
     → payCallback           → 校验金额 → markPaid（乐观锁幂等）
                              → 更新销量、累计消费、积分、会员等级
```

**兜底**：若回调延迟，前端支付成功后会调 `pay.queryPay` 主动查询并补偿。
`markPaid` 用 `where({ status: 'pending_pay' })` 做乐观锁，回调与查询并发时只会生效一次。

## 八、常见问题

**Q：提示「云函数未部署」**
右键对应的云函数目录重新「上传并部署：云端安装依赖」。注意不要只选「上传触发器」。

**Q：点击编译就提示「数据集合不存在」**
这是首次运行的正常现象——数据库还是空的。进入「我的」页点「🔧 一键初始化」即可，
详见第五节。若按钮不出现，说明 `seed` 云函数没部署成功。

**Q：支付报 `PAY_NOT_CONFIGURED`**
`settings/pay` 文档没建，或 `subMchId` 为空。个人主体小程序无法使用支付。

**Q：管理台进不去，提示无权访问**
当前账号 `role` 不是 `admin`。若已有其他管理员，需由对方调用 `seed.grantAdmin` 授权。

**Q：改了共享逻辑但云函数行为没变**
忘记运行 `bash scripts/sync-shared.sh`，或同步后没重新上传云函数。

**Q：下单提示库存不足，但商品明明有货**
库存扣减是事务 + 条件更新，说明同一时刻有其他订单占用。刷新购物车会拉取最新库存。
