# 部署与配置指南

## 一、前置准备

| 项目 | 说明 | 是否必需 |
| --- | --- | --- |
| 小程序 AppID | 在 [微信公众平台](https://mp.weixin.qq.com) 注册「小程序」账号 | 必需 |
| 微信开发者工具 | [下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，Stable 版即可 | 必需 |
| 云开发环境 | 开发者工具内一键开通，有免费额度 | 必需 |
| 微信支付商户号 | 需企业主体小程序，个人主体无法使用支付 | 支付功能必需 |

> **个人主体小程序**：除「微信支付」外其余功能均可正常跑通。支付相关页面会提示
> `未配置微信支付商户号`，不影响下单、预约、会员和后台管理的调试。

---

## 二、导入项目

1. 打开微信开发者工具 → **导入项目**
2. 目录选择本仓库根目录，AppID 填你自己的（测试可选「测试号」）
3. 后端服务选择「微信云开发」

导入后把 `project.config.json` 里的 `appid` 改成你的真实 AppID：

```json
{ "appid": "wx这里换成你的appid" }
```

---

## 三、开通云开发

1. 工具栏点击 **云开发** → 开通 → 新建环境（如 `flower-prod`）
2. 记下环境 ID。代码里用的是 `DYNAMIC_CURRENT_ENV`，会自动指向当前环境，**无需手填**

---

## 四、部署云函数

云函数共 9 个。**首次部署请逐个操作**：

> 右键 `cloudfunctions/<函数名>` → **上传并部署：云端安装依赖**

部署顺序不限，建议按下表逐一确认：

| 云函数 | 作用 | 特殊配置 |
| --- | --- | --- |
| `login` | 授权登录、昵称头像、手机号 | 手机号功能需在 mp 后台开通「手机号快速验证」 |
| `shop` | 商品、分类、店铺信息 | — |
| `order` | 下单、查单、取消、收货 | — |
| `pay` | 微信支付统一下单 | 需配置商户号，见第六节 |
| `payCallback` | 支付结果回调 | 由 `pay` 指定调用，无需单独配置 |
| `reservation` | 预约订花 | — |
| `member` | 会员、优惠券、地址 | — |
| `admin` | 后台管理 | — |
| `seed` | 初始化数据与管理员 | 上线后建议删除 |

### 共享库说明

9 个云函数共用 `shared/common.js`。因为云函数各自独立打包、无法跨目录 `require`，
所以每个函数目录下都有一份复制（`cloudfunctions/<函数名>/common.js`）。

> **源文件为什么不放在 `cloudfunctions/` 下**：开发者工具会把 `cloudfunctionRoot`
> （即 `cloudfunctions/`）下的**每个子目录**都识别为一个云函数。共享库目录没有
> `index.js`，上传时必然报错。因此源文件放在仓库根的 `shared/`。
>
> 同理，**不要在 `cloudfunctions/` 下新建任何非云函数目录**。

**修改共享逻辑时，只改 `shared/common.js`，然后运行：**

```bash
bash scripts/sync-shared.sh
```

同步后需要重新上传受影响的云函数。

## 五、初始化数据库

### 5.1 创建集合

在 **云开发控制台 → 数据库** 中创建以下 10 个集合：

| 集合名 | 用途 | 建议权限 |
| --- | --- | --- |
| `users` | 用户档案、会员等级、角色 | 仅创建者可读写 |
| `categories` | 商品分类 | 所有人可读 |
| `products` | 商品 | 所有人可读 |
| `orders` | 订单 | 仅创建者可读写 |
| `reservations` | 预约单 | 仅创建者可读写 |
| `coupons` | 优惠券模板 | 所有人可读 |
| `user_coupons` | 用户已领券 | 仅创建者可读写 |
| `addresses` | 收货地址 | 仅创建者可读写 |
| `settings` | 店铺、轮播、支付配置 | 所有人可读 |
| `stock_logs` | 库存变更日志 | 仅管理端可读写 |

> 权限只影响小程序端的直连数据库操作。本项目所有读写都走云函数（管理员权限），
> 因此即使全设为「仅创建者可读写」也能正常工作，这样更安全。

### 5.2 设为店主

1. 编译运行小程序 → 进入「我的」
2. 点击 **「首次使用？点此将当前账号设为店主」**
3. 该入口仅在店铺尚无任何管理员时有效；之后需由现有管理员通过 `seed.grantAdmin` 授权

### 5.3 灌入示例数据

「我的」→「商家管理台」→「初始化示例数据」，会创建：

- 6 个分类（玫瑰花束、混搭花束、永生花、绿植盆栽、节日限定、开业花篮）
- 8 个示例商品（含花材、花语、包装等完整信息）
- 3 张优惠券模板（新客立减、满减、会员折扣）
- 店铺信息与节日表

> **商品图片需自行上传**：示例数据的 `cover` 为空，页面会显示 🌸 占位符。
> 到「商品管理 → 编辑商品 → 商品图片」上传即可，图片存入云存储。

### 5.4 建议的数据库索引

数据量上来后在控制台为这些字段建索引：

| 集合 | 索引字段 |
| --- | --- |
| `products` | `status`（升序）、`categoryId`（升序）、`sales`（降序） |
| `orders` | `_openid`（升序）、`status`（升序）、`createdAt`（降序）、`orderNo`（升序，唯一） |
| `reservations` | `_openid`、`deliveryDate`（升序）、`status` |
| `user_coupons` | `_openid` + `status` 联合索引 |
| `addresses` | `_openid` |

## 六、配置微信支付

### 6.1 开通云调用支付

1. 云开发控制台 → **扩展能力 / 微信支付** → 绑定商户号
2. 在商户平台完成「**云开发支付授权**」确认

### 6.2 写入商户号

在 `settings` 集合中创建一个 **文档 ID 为 `pay`** 的记录：

```json
{
  "_id": "pay",
  "subMchId": "1900000109",
  "shopName": "花知道鲜花"
}
```

也可以改用环境变量 `WX_SUB_MCH_ID`（在云函数配置中设置）。

### 6.3 支付链路说明

```
小程序 order.create          → 事务扣库存、写订单（pending_pay）
     → pay.prepay            → cloudPay.unifiedOrder，返回支付参数
     → wx.requestPayment     → 用户输入密码
     → 微信支付后台           → 回调 payCallback 云函数
     → payCallback           → 校验金额 → markPaid（乐观锁幂等）
                              → 更新销量、累计消费、积分、会员等级
```

**兜底**：若回调延迟，前端支付成功后会调 `pay.queryPay` 主动查询并补偿。
`markPaid` 用 `where({ status: 'pending_pay' })` 做乐观锁，回调与查询并发时只会生效一次。

## 八、常见问题

**Q：提示「云函数未部署」**
右键对应的云函数目录重新「上传并部署：云端安装依赖」。注意不要只选「上传触发器」。

**Q：提示「数据库集合不存在」**
按第五节在控制台创建对应集合，集合名必须与表中完全一致。

**Q：支付报 `PAY_NOT_CONFIGURED`**
`settings/pay` 文档没建，或 `subMchId` 为空。个人主体小程序无法使用支付。

**Q：管理台进不去，提示无权访问**
当前账号 `role` 不是 `admin`。若已有其他管理员，需由对方调用 `seed.grantAdmin` 授权。

**Q：改了共享逻辑但云函数行为没变**
忘记运行 `bash scripts/sync-shared.sh`，或同步后没重新上传云函数。

**Q：下单提示库存不足，但商品明明有货**
库存扣减是事务 + 条件更新，说明同一时刻有其他订单占用。刷新购物车会拉取最新库存。
